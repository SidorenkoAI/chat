# Урок 12. CSS — теория и разбор кода

На уроке 11 мы описали **что** есть на странице. Сегодня описываем, **как** это выглядит. Для этого есть язык **CSS**. В HTML меняется одна строка, а весь новый код лежит в файле `style.css`.

## Подключаем стили

В `<head>` файла `index.html` добавилась строка:

```html
<link rel="stylesheet" href="style.css">
```

- `<link>` — «связать» страницу с другим файлом. Закрывающего тега нет.
- `rel="stylesheet"` — какая это связь: «таблица стилей».
- `href="style.css"` — где лежит файл. Просто имя — значит, в той же папке, что и `index.html`.

Почему стили в отдельном файле, а не прямо в HTML? Так разметка остаётся чистой, а один `style.css` можно подключить к нескольким страницам. Например, к `about.html` из заданий урока 11.

## Подробный разбор: как устроено правило CSS

```css
.message {
  padding: 8px 12px;
  border-radius: 14px;
}
```

- `.message` — **селектор**: к каким элементам применить правило.
- В фигурных скобках — **объявления**: `свойство: значение;`. Точка с запятой в конце каждого обязательна, иначе браузер склеит два объявления в одно непонятное и пропустит оба.
- Комментарии пишутся так: `/* текст */`. Решётка `#`, как в Python, в CSS означает совсем другое (см. ниже).

**Селекторы этого урока:**

| Селектор | Кого выбирает | Пример у нас |
|---|---|---|
| `header` | все элементы `<header>` | шапка |
| `.message` | все элементы с классом `message` | все сообщения |
| `#messages` | элемент с `id="messages"` | список сообщений |
| `.message.mine` | элементы, у которых **оба** класса, `message` и `mine` (без пробела!) | свои сообщения |
| `header h1` | `<h1>`, лежащие **где-то внутри** `<header>` (через пробел) | заголовок в шапке |
| `html, body` | и `<html>`, и `<body>` (через запятую) | — |
| `button:hover` | кнопка, **когда на неё наведена мышь** | — |
| `#online li::before` | «невидимый первый кусочек» внутри каждого `<li>` | зелёная точка |

Обратите внимание на разницу между `.message.mine` (один элемент с двумя классами) и `.message .mine` (элемент `.mine` **внутри** `.message`). Один пробел меняет смысл.

### Подробный разбор: каскад — кто победит

Что будет, если два правила задают одному элементу разный цвет? Например:

```css
.message { background: var(--panel); }       /* белый */
.message.mine { background: var(--accent); } /* синий */
```

Побеждает **более точный** селектор. Два класса точнее одного, поэтому своё сообщение будет синим. Если точность одинаковая, побеждает правило, которое написано **ниже** в файле. Отсюда и слово «каскадные» в названии.

Этим мы и пользуемся: сначала описываем общий вид всех `.message`, а ниже только **отличия** для `.mine`, `.private`, `.system`.

## Шаг 1. Переменные с цветами

```css
:root {
  --bg: #eef1f6;
  --panel: #ffffff;
  --text: #1f2430;
  --muted: #6f7687;
  --line: #dde1ea;
  --accent: #4f6bed;
  --private: #8a5cd6;
}
```

- `:root` — корень страницы, то есть элемент `<html>`. То, что объявлено здесь, видно во всех правилах.
- `--bg`, `--accent` и т. д. — **переменные CSS**. Их имя обязательно начинается с двух минусов. Пользуются ими так: `var(--accent)`.
- `#4f6bed` — цвет в шестнадцатеричной записи: по две цифры на красный, зелёный и синий (от `00` до `ff`). Подбирать цвета удобно в F12: щёлкнуть по квадратику цвета в Styles, откроется пипетка. Можно писать и словами: `white`, `red`.

Зачем переменные? Синий цвет используется в шести местах: имя автора, свои сообщения, кнопка… Захотим зелёную тему — поменяем одну строку. На уроке 17 мы так сделаем тёмную тему: просто подменим значения переменных.

| Переменная | Что красит |
|---|---|
| `--bg` | фон страницы |
| `--panel` | фон шапки, подвала, колонки и чужих сообщений |
| `--text` | основной текст |
| `--muted` | второстепенный текст (серый) |
| `--line` | тонкие линии-разделители |
| `--accent` | главный цвет: кнопки, свои сообщения, имена |
| `--private` | личные сообщения |

## Шаг 2. Страница на всё окно

```css
html, body {
  height: 100%;
  margin: 0;
}

body {
  display: flex;
  flex-direction: column;
  background: var(--bg);
  color: var(--text);
  font-family: "Segoe UI", Arial, sans-serif;
  font-size: 16px;
}
```

- `height: 100%` — высота как у окна. По умолчанию страница высотой ровно со своё содержимое, а нам нужно, чтобы форма была прижата к низу окна, даже если сообщений мало.
- `margin: 0` — убрать отступ, который браузер по умолчанию делает вокруг `<body>` (8 пикселей).
- `display: flex; flex-direction: column` — дети `<body>` (`header`, `main`, `footer`) встают **столбиком**. Про flexbox подробно — ниже.
- `background` — фон, `color` — цвет текста.
- `font-family` — шрифт. Перечисляется несколько «на выбор»: если на компьютере нет Segoe UI (он есть в Windows), берётся Arial, если нет и его — любой шрифт без засечек (`sans-serif`).
- `font-size: 16px` — размер шрифта в пикселях.

### Подробный разбор: flexbox

`display: flex` превращает элемент во **flex-контейнер**, а его прямых детей — в элементы, которые он раскладывает:

| Свойство контейнера | Что делает |
|---|---|
| `flex-direction: row` / `column` | раскладывать в строку (по умолчанию) или в столбик |
| `justify-content` | как распределить элементы **вдоль** направления: `space-between` — первый в начало, последний в конец, остальное место между ними |
| `align-items` | как выровнять **поперёк** направления: `center` — по центру |
| `gap: 8px` | промежуток между элементами |

| Свойство элемента | Что делает |
|---|---|
| `flex: 1` | «забери всё свободное место» |
| `align-self` | выровнять **этот** элемент поперёк направления иначе, чем остальных: `flex-start` — в начало, `flex-end` — в конец, `center` — по центру |

Наша страница — это flexbox, вложенный во flexbox:

```
body  (столбик)
├── header        (строка: h1 ←→ p)
├── main          (строка, flex: 1 — растягивается по высоте)
│   ├── #messages (столбик, flex: 1 — растягивается по ширине)
│   └── aside     (ширина 200px)
└── footer
    └── #send-form (строка: input растягивается, button справа)
```

## Шаг 3. Шапка

```css
header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 10px 20px;
  background: var(--panel);
  border-bottom: 1px solid var(--line);
}

header h1 {
  margin: 0;
  font-size: 22px;
}

header p {
  margin: 0;
  color: var(--muted);
}
```

- `display: flex` + `justify-content: space-between` — `h1` прижат влево, `p` вправо.
- `align-items: center` — оба по центру по высоте. Без этого заголовок и абзац разной высоты съехали бы.
- `padding: 10px 20px` — внутренний отступ: 10 пикселей сверху и снизу, 20 слева и справа (см. блочную модель ниже).
- `border-bottom: 1px solid var(--line)` — линия снизу: толщина, вид (`solid` — сплошная, `dashed` — пунктир), цвет.
- `margin: 0` у `h1` и `p` — у заголовков и абзацев браузер сам добавляет отступы сверху и снизу. В шапке они лишние.

### Подробный разбор: блочная модель

Каждый элемент — это прямоугольник из четырёх слоёв (изнутри наружу):

```
┌──────────── margin (внешний отступ, прозрачный) ────────────┐
│  ┌───────── border (рамка) ──────────────────────────────┐  │
│  │  ┌────── padding (внутренний отступ, цвета фона) ───┐ │  │
│  │  │                содержимое                        │ │  │
│  │  └──────────────────────────────────────────────────┘ │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

- `padding` — отступ **внутри** рамки. Фон элемента его закрашивает. Пузырь сообщения кажется «воздушным» благодаря `padding: 8px 12px`.
- `margin` — отступ **снаружи**, расстояние до соседей.
- Значения можно писать по-разному: `padding: 10px` — со всех сторон; `padding: 10px 20px` — сверху/снизу и слева/справа; `margin: 0 0 8px` — сверху, слева/справа, снизу.

В F12 → Elements → вкладка Computed эта модель нарисована для выбранного элемента с настоящими числами.

## Шаг 4. Середина: сообщения и колонка

```css
main {
  flex: 1;
  display: flex;
  min-height: 0;
}

#messages {
  flex: 1;
  display: flex;
  flex-direction: column;
  gap: 8px;
  padding: 16px 20px;
  overflow-y: auto;
}
```

- `main { flex: 1 }` — середина забирает всю высоту между шапкой и подвалом.
- `main { display: flex }` — внутри `main` сообщения и колонка стоят **в строку**.
- `#messages { flex: 1 }` — список сообщений забирает всю ширину, кроме колонки.
- `#messages { display: flex; flex-direction: column; gap: 8px }` — сообщения столбиком, с промежутком 8 пикселей.
- `overflow-y: auto` — если сообщения не помещаются по высоте, появляется полоса прокрутки **только у списка**. Шапка и форма остаются на месте.

### Подробный разбор: загадочное `min-height: 0`

Без этой строчки при большом количестве сообщений прокрутка появляется не у списка, а у всей страницы, и форма уезжает вниз за край окна.

Причина в правиле flexbox: элемент не может стать **меньше своего содержимого**. Для `main` по умолчанию это значит «я не меньше, чем все сообщения вместе». Он растёт, распирает `body`, и `overflow-y: auto` у списка не срабатывает: списку ведь хватает места! `min-height: 0` разрешает `main` быть меньше содержимого. Тогда он остаётся высотой с окно, а лишнее прокручивается внутри `#messages`.

Чтобы увидеть это своими глазами, скопируйте в HTML штук двадцать сообщений и уберите `min-height: 0`.

## Шаг 5. Пузыри сообщений

```css
.message {
  max-width: 70%;
  padding: 8px 12px;
  border-radius: 14px;
  background: var(--panel);
  border: 1px solid var(--line);
  align-self: flex-start;
}

.message .author {
  display: block;
  font-size: 13px;
  color: var(--accent);
}
```

- `max-width: 70%` — пузырь не шире 70% списка: длинное сообщение переносится на несколько строк, а не тянется через весь экран.
- `border-radius: 14px` — скругление углов. Чем больше число, тем круглее.
- `align-self: flex-start` — прижать пузырь к **левому** краю. Без этого во flex-столбике все элементы растягиваются на всю ширину.
- `.message .author` (через пробел!) — элемент с классом `author` **внутри** сообщения. `display: block` делает имя блочным (урок 11): оно встаёт отдельной строкой над текстом.

Отличия видов сообщений — ниже по файлу, чтобы перебить общие правила:

```css
.message.mine {
  align-self: flex-end;
  background: var(--accent);
  border-color: var(--accent);
  color: white;
}

.message.mine .author {
  color: white;
}
```

Своё сообщение: прижать **вправо** (`flex-end`), фон синий, текст белый. Имя автора тоже белое, иначе синее имя на синем фоне пропадёт.

```css
.message.private {
  border: 2px dashed var(--private);
}

.message.private .author {
  color: var(--private);
}
```

Личное: рамка потолще и пунктиром (`dashed`), имя фиолетовое.

```css
.message.system {
  align-self: center;
  background: none;
  border: none;
  color: var(--muted);
  font-size: 14px;
}
```

Системное: по центру, без фона (`none`) и без рамки, мелко и серым. Это уже не «пузырь», а строчка-уведомление.

## Шаг 6. Колонка «В сети»

```css
aside {
  width: 200px;
  padding: 16px 20px;
  background: var(--panel);
  border-left: 1px solid var(--line);
}

aside h2 {
  margin: 0 0 8px;
  font-size: 15px;
  color: var(--muted);
}

#online {
  list-style: none;
  margin: 0;
  padding: 0;
}

#online li {
  padding: 4px 0;
}

#online li::before {
  content: "● ";
  color: #2e9d62;
}
```

- `width: 200px` — колонка фиксированной ширины. Её flexbox не растягивает: `flex: 1` у неё нет.
- `list-style: none` — убрать точки у списка. `margin: 0; padding: 0` — убрать отступ слева, который браузер делает спискам.
- `::before` — **псевдоэлемент**: кусочек содержимого, который CSS добавляет в начало элемента. В HTML его нет, но на экране он виден. `content: "● "` — что именно добавить: кружок и пробел, `color` — зелёный. Так у каждого человека в сети появляется «лампочка».

## Шаг 7. Форма отправки

```css
footer {
  padding: 10px 20px;
  background: var(--panel);
  border-top: 1px solid var(--line);
}

#send-form {
  display: flex;
  gap: 8px;
}

#text {
  flex: 1;
  padding: 10px 12px;
  font-size: 16px;
  border: 1px solid var(--line);
  border-radius: 10px;
}

button {
  padding: 10px 18px;
  font-size: 16px;
  color: white;
  background: var(--accent);
  border: none;
  border-radius: 10px;
  cursor: pointer;
}

button:hover {
  opacity: 0.85;
}
```

- `#send-form { display: flex }` — поле и кнопка в строку. `#text { flex: 1 }` — поле забирает всю ширину, кроме кнопки.
- `font-size: 16px` у поля важен на телефонах: если шрифт в поле меньше 16 пикселей, iPhone при нажатии увеличивает страницу.
- `cursor: pointer` — курсор-«ладошка» над кнопкой, как над ссылкой.
- `button:hover` — когда мышь над кнопкой. `opacity: 0.85` — непрозрачность 85%: кнопка чуть бледнеет и «отзывается» на мышь.

## Подробный разбор: как отлаживать CSS

1. **F12 → Elements**, выбрать элемент (или правый клик по нему на странице → «Просмотреть код»).
2. Справа в **Styles** — все правила, которые к нему применились, сверху самые сильные. Перебитые свойства **зачёркнуты**: сразу видно, какое правило победило.
3. Свойство с ошибкой (опечатка в имени или значении) зачёркнуто и помечено жёлтым треугольником.
4. Можно снимать галочки у свойств, менять числа стрелками вверх/вниз и дописывать новые свойства. Когда получилось — перенесите в `style.css`, в браузере правки не сохраняются.
5. Если стили не применились вообще, откройте вкладку **Network** и обновите страницу. `style.css` с кодом 404 значит, что файл не найден: проверьте имя и `href`.
