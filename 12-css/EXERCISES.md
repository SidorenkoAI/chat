## Лёгкие

### 1. Своя цветовая схема

Перекрась чат в свои цвета: например, зелёный, оранжевый или «как в любимом мессенджере». Поменяй хотя бы фон страницы, главный цвет и цвет личных сообщений.

- Тебе не нужно искать все места, где встречается синий. Посмотри, что объявлено в `:root`.
- Подбирать цвета удобно пипеткой в F12: щёлкни по цветному квадратику рядом со значением.
- Проверь, что текст везде читается: белые буквы на светло-жёлтом фоне не увидит никто.

### 2. Отклик на мышь

Сделай так, чтобы интерфейс «отзывался» на мышь:
- у сообщения под мышью появляется лёгкая тень;
- ник в списке «В сети» под мышью подсвечивается фоном;
- всё это появляется плавно, а не рывком.

- Состояние «мышь над элементом» — псевдокласс `:hover`. Как у кнопки в коде урока.
- Тень — свойство `box-shadow`. Попробуй что-нибудь вроде `0 2px 8px rgba(0, 0, 0, 0.15)` и поиграй числами.
- Плавность — свойство `transition`: какое свойство анимировать и сколько секунд.

### 3. Время мелким шрифтом

Добавь каждому сообщению (кроме системных) время, как в задании 2 урока 11, и оформи его: мелко, серо, справа от имени автора.

- В HTML время — тег `<time class="time">`. Где его поставить, чтобы оно оказалось рядом с именем?
- Имя автора сейчас блочное (`display: block`) и занимает всю строку. Как поставить время в ту же строку? Подумай про flexbox для строки «имя + время».
- У своего сообщения фон синий: серое время на нём будет плохо видно. Тут пригодится правило `.message.mine .time`.

## Средние

### 4. Аватарки-кружки

Перед каждым сообщением (кроме системных) — цветной кружок с первой буквой имени, как в настоящих мессенджерах. Кружок стоит **слева от пузыря**, а не внутри него.

- Кружок — это квадрат с одинаковыми `width` и `height` и с `border-radius: 50%`.
- Букву по центру кружка поставь flexbox'ом: `align-items` и `justify-content`.
- Чтобы кружок стоял рядом с пузырём, сообщение и аватарку можно обернуть в общий блок-строку. Придумай для него класс, например `row`.
- Разным людям — разные цвета: добавь аватаркам классы, например `avatar blue` или `avatar green`.

### 5. Шапка с градиентом

Сделай шапку яркой: фон-градиент (плавный переход между двумя цветами), белый текст, а перед названием — эмодзи-логотип 💬.

- Градиент задаётся в `background`: `linear-gradient(направление, цвет1, цвет2)`. Направление можно указать, например, как `90deg` (слева направо).
- Эмодзи можно вставить прямо в HTML. Или, интереснее, через `::before` у `h1`, как зелёные точки у списка «В сети».
- Не забудь про цвет «Вы вошли как…»: серый на градиенте будет нечитаемым.

### 6. Тёмная тема по настройке системы

Если в Windows (или на телефоне) включена тёмная тема, чат тоже должен становиться тёмным.

- В CSS можно узнать настройку системы: `@media (prefers-color-scheme: dark) { ... }`. Правила внутри действуют, только когда у пользователя тёмная тема.
- Тебе не нужно переписывать все правила. Подумай, что достаточно поменять внутри `@media`, раз все цвета лежат в переменных.
- Проверить можно без смены темы Windows: F12 → три точки → More tools → Rendering → Emulate CSS media feature prefers-color-scheme.
- Не забудь поле ввода: у него свой белый фон от браузера.

## Посложнее

### 7. Карточка входа

Сделай страницу `login.html` (макет из задания 6 урока 11) и оформи её: белая карточка с формой **ровно по центру экрана**, подписи над полями, поля на всю ширину карточки, две кнопки в ряд.

- Подключи к странице тот же `style.css`. Новые правила дописывай в него.
- По центру экрана по обеим осям: у родителя `display: flex`, `align-items: center` и `justify-content: center`, плюс высота на всё окно.
- Поля «на всю ширину» и «друг под другом» проще всего получить, если сделать саму форму flex-столбиком.
- Вторая кнопка («Зарегистрироваться») может быть «контурной»: прозрачный фон и цветная рамка.

### 8. Анимация появления сообщений

При открытии страницы сообщения появляются по очереди: каждое выезжает снизу и проявляется из прозрачного. На уроке 13 эта же анимация сработает для каждого нового сообщения.

- Анимация в CSS описывается так: `@keyframes имя { from { ... } to { ... } }`, а подключается свойством `animation: имя 0.3s ease-out`.
- «Выезжает снизу» — `transform: translateY(10px)` в начале и `none` в конце. «Проявляется» — `opacity` от `0` до `1`.
- «По очереди» — задержка `animation-delay` у разных сообщений. Можно воспользоваться селектором `:nth-child(2)`, `:nth-child(3)` и т. д.
- Если сообщение мигает в конце анимации, посмотри свойство `animation-fill-mode`.
