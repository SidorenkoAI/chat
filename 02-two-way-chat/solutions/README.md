# Эталонные решения к заданиям урока 2

Каждая папка — полная, самостоятельно запускаемая копия кода урока с **одним** применённым заданием (см. [EXERCISES.md](../EXERCISES.md)). Изменены только файлы, указанные в таблице; остальные совпадают с кодом урока.

Запуск: открыть папку решения, `python server.py`, затем в другом терминале `python client.py`.

| Папка | Задание | Изменённые файлы |
|---|---|---|
| [01-timestamps](01-timestamps) | Время получения сообщения | `client.py`, `server.py` |
| [02-names](02-names) | Имена собеседников | `client.py`, `server.py` |
| [03-no-empty-messages](03-no-empty-messages) | Не отправлять пустые сообщения | `client.py`, `server.py` |
| [04-exit-both-sides](04-exit-both-sides) | Команда `/exit` с обеих сторон | `client.py`, `server.py` |
| [05-time-autoreply](05-time-autoreply) | Автоответ на `/time` | `server.py` |
| [06-dialog-log](06-dialog-log) | Журнал переписки в файл | `server.py` |
| [07-bot-mode](07-bot-mode) | Режим бота | `server.py` |
| [08-reconnect](08-reconnect) | Повторные попытки подключения | `client.py` |
