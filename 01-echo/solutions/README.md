# Эталонные решения к заданиям урока 1

Каждая папка — полная, самостоятельно запускаемая копия кода урока с **одним** применённым заданием (см. [EXERCISES.md](../EXERCISES.md)). Изменены только файлы, указанные в таблице; остальные совпадают с кодом урока.

Запуск: открыть папку решения, `python server.py`, затем в другом терминале `python client.py`.

| Папка | Задание | Изменённые файлы |
|---|---|---|
| [01-upper-echo](01-upper-echo) | Эхо заглавными буквами | `server.py` |
| [02-numbered-replies](02-numbered-replies) | Нумерация ответов | `server.py` |
| [03-empty-message](03-empty-message) | Пустые сообщения | `server.py` |
| [04-exit-command](04-exit-command) | Команда `/exit` | `client.py`, `server.py` |
| [05-server-commands](05-server-commands) | Команды `/reverse` и `/len` | `server.py` |
| [06-many-clients-in-turn](06-many-clients-in-turn) | Сервер не выключается после ухода клиента | `server.py` |
| [07-port-from-argv](07-port-from-argv) | Порт из командной строки | `client.py`, `server.py` |
| [08-guess-number](08-guess-number) | Игра «Угадай число» | `client.py`, `server.py` |
