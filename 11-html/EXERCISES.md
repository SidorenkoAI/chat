Ниже — подсказки, **не готовый код**. Эталонные решения — в папке [solutions](solutions/README.md). Чтобы проверить себя, открывай `index.html` (и новые страницы) в браузере после каждого изменения и не забывай обновлять страницу (F5).

## Лёгкие

### 1. Ещё сообщения

Добавь в список ещё три сообщения: от Вовы, ещё одно своё (`mine`) и системное «Вова присоединился к чату». В одном из сообщений используй эмодзи, а ещё одно сделай длинным, на 2–3 строки текста.

- Скопируй готовый `<div class="message">…</div>` и поменяй текст. Следи, чтобы каждый `<div>` был закрыт.
- Эмодзи можно вставить прямо в текст. В Windows их открывает сочетание клавиш **Win + .** (точка).
- Порядок сообщений в HTML — это и порядок на экране.

### 2. Время у сообщений

У каждого обычного, своего и личного сообщения должно быть видно время отправки, например `10:15`.

- Для даты и времени в HTML есть специальный тег `<time>`. Его можно положить внутрь сообщения рядом с автором.
- У тега `<time>` есть атрибут `datetime`. В нём время записывают «для компьютера», например `datetime="10:15"`, а внутри тега — «для человека».
- Чтобы потом было удобно оформлять, дай ему класс, например `class="time"`.

### 3. Подсказки для поля ввода

Сделай поле ввода «умнее»:
- курсор сразу стоит в поле, когда страница открылась;
- нельзя ввести больше 500 символов;
- пустую форму нельзя отправить, браузер сам покажет предупреждение.

- Всё это делается одними атрибутами `<input>`, без программирования. Поищи в интернете атрибуты `autofocus`, `maxlength`, `required`.
- Некоторые атрибуты пишутся без значения: просто слово внутри тега.
- Проверь: нажми «Отправить» с пустым полем. Что показал браузер?

## Средние

### 4. Страница «О чате»

Сделай вторую страницу `about.html`: заголовок, пара абзацев о том, что это за чат, список «Что умеет чат» (5–6 пунктов) и ссылку «← Вернуться в чат». На главной странице в шапке должна появиться ссылка «О чате».

- Ссылка — тег `<a>`. Куда ведёт ссылка, пишут в атрибуте `href`.
- Если файл лежит в той же папке, в `href` достаточно написать его имя: `about.html`.
- Не забудь, что у новой страницы тоже нужен весь скелет: `<!DOCTYPE html>`, `<head>` с `charset` и `title`, `<body>`.
- Что умеет чат? Вспомни уроки 1–10: история, пароли, личные сообщения, шифрование…

### 5. Таблица команд

Под списком «В сети» добавь раздел «Команды» с таблицей из двух колонок: «Команда» и «Что делает». Строки: `/who`, `/w ник текст` и ещё одна, придуманная тобой.

- Таблица строится из тегов `<table>` (вся таблица), `<tr>` (строка), `<th>` (ячейка-заголовок) и `<td>` (обычная ячейка).
- Таблица состоит из строк, а строки — из ячеек. Не наоборот!
- Чтобы команды выглядели как код, оберни их в тег `<code>`.

### 6. Макет экрана входа

Сделай файл `login.html` — макет экрана входа в чат. На нём заголовок, поле «Логин», поле «Пароль» и две кнопки: «Войти» и «Зарегистрироваться». Добавь на главную ссылку на этот макет.

- Поля и кнопки положи внутрь `<form>`.
- Для пароля нужен такой тип поля, чтобы вместо букв были точки. Какой `type` у `<input>`?
- Подписи к полям делаются тегом `<label>`. Его атрибут `for` должен совпадать с `id` поля. Тогда щелчок по подписи ставит курсор в поле. Проверь!

## Посложнее

### 7. Аватарки-буквы

Перед именем автора каждого сообщения (кроме системных) добавь «аватарку» — элемент с первой буквой имени: `Б` для Бори, `А` для Ани. Сейчас это будет просто буква, а на уроке 12 мы превратим её в цветной кружок.

- Какой тег подойдёт для маленького кусочка внутри строки, у которого нет особого смысла?
- Дай аватарке класс, например `avatar`. Без класса на следующем уроке её будет не найти.
- Подумай, где аватарка должна стоять в дереве: внутри `<div class="message">`, перед `<b class="author">`.

### 8. Почини сломанную страницу

Создай файл `broken.html` и скопируй в него этот код. В нём **шесть ошибок**. Найди и исправь их все.

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <title>Сломанный чат</title>
</head>
<body>
  <h1>Сломанный чат</h1>
  <p>Вы вошли как <b>Вова</p>

  <div class="message">
    <b class="author">Аня</b>
    <span class="text>Кто-нибудь видит это сообщение?</span>

  <div class="message">
    <b class="author">Боря</b>
    <span class="text">Вижу!</span>
  </div>

  <li>Аня</li>
  <li>Боря</li>

  <input type="text" placeholder="Сообщение…"></input>
</body>
</html>
```

- Открой страницу в браузере и в F12 → Elements. Как браузер «понял» эти ошибки? Что стало жирным? Что куда вложилось?
- Подсказки по видам ошибок: незакрытый тег (две штуки), незакрытые кавычки, пункты списка без самого списка, лишний закрывающий тег у элемента, которому он не нужен, и одна пропавшая строка в `<head>`. Без неё на некоторых компьютерах будут кракозябры.
- PyCharm подсвечивает часть ошибок, наведи на подсвеченное место мышью.
