## Средние

### 3. Общее меню и заголовок вкладки

Сейчас ссылки «← На главную» скопированы во все страницы, а у вкладок нет названия. Сделайте функцию `page(title, body)`, которая собирает **полную** страницу: `<!DOCTYPE html>`, `<head>` с `<meta charset="utf-8">` и `<title>`, общее меню из ссылок на все страницы и переданный `body`. Все страницы возвращают `page(...)`.

- Вспомните скелет HTML-страницы из урока 11.
- Функция-помощник — обычная функция Python **без** `@app.route`: её никто не открывает по адресу, её вызывают другие функции.
- Подумайте: что нужно поменять, чтобы добавить в меню новый пункт? Сколько мест?
- На следующем уроке эту же задачу решат **шаблоны**, и гораздо удобнее.

### 4. Квадрат числа

Страница `/square/7` пишет «7 × 7 = 49». А что будет, если открыть `/square/abc`?

- В маршруте можно указать тип: `<int:n>`. Тогда Flask сам превратит часть адреса в число, а для `abc` ответит 404, и функция вообще не вызовется.
- Попробуйте сначала без `int:` — что придёт в функцию? Какая ошибка будет при умножении?
- А `/square/-5`? Посмотрите в документации Flask (или проверьте сами), подходят ли отрицательные числа под `int`.

### 5. Счётчик посещений

На главной странице внизу написано «Эту страницу открыли 17 раз». Каждый F5 увеличивает число.

- Где хранить число, чтобы оно не обнулялось при каждом запросе? Не внутри функции.
- Чтобы изменить глобальную переменную внутри функции, нужно слово `global`.
- После перезапуска сайта счётчик обнулится. Почему? Как сделать иначе — в уроке 23 (база данных).
- Подумайте: Flask обслуживает каждый запрос в своём потоке. Что может случиться, если два запроса придут одновременно? Что мы использовали в уроке 3, чтобы потоки не мешали друг другу?

### 6. Своя страница 404

Вместо английского «Not Found» — своя страница: «Такой страницы нет 😢» и ссылка на главную. Код ответа должен остаться **404**.

- Для этого есть декоратор `@app.errorhandler(404)`. Функция под ним получает один параметр — ошибку.
- Как вернуть свой код ответа? Посмотрите шпаргалку в THEORY.md.
- Проверьте в F12 → Network, что код действительно 404, а не 200.

## Посложнее

### 7. Параметры после `?`

Страница `/hello?name=Аня&times=3` трижды пишет «Привет, Аня!». Без параметров — один раз «Привет, гость!».

- Часть адреса после `?` называется **строкой запроса** (query string). Пары `ключ=значение` разделяются `&`.
- Во Flask их можно прочитать из `request.args`. Это почти словарь. `request` импортируется из `flask`.
- `request.args.get("name", "гость")` — значение или «по умолчанию».
- Для чисел у `get` есть параметр `type=int`. Что будет, если написать `times=abc`?
- Не забудьте про `escape`! Проверьте адрес `/hello?name=<b>Вася`.
- Ограничьте `times`, например, числом 100. Иначе кто-нибудь откроет `?times=100000000`.

### 8. Время для программ

Страница `/api/time` возвращает не HTML, а **JSON**: `{"time": "12:05:33", "date": "2026-10-04"}`.

- Если функция вернёт словарь, Flask сам превратит его в JSON.
- Сравните в F12 → Network заголовок `Content-Type` у `/time` и у `/api/time`.
- Такие адреса нужны не людям, а программам. Попробуйте прочитать его из Python:
  ```python
  import json, urllib.request
  data = json.load(urllib.request.urlopen("http://127.0.0.1:5000/api/time"))
  print(data["time"])
  ```
- На уроке 22 так будет работать наш чат: страница будет спрашивать у сайта новые сообщения в формате JSON.
