# Урок 19. Flask: первый сайт — теория и разбор кода

## Как браузер получает страницу

Когда вы набираете в браузере `http://127.0.0.1:5000/about`, происходит вот что.

1. Браузер разбирает адрес:
   - `http://` — способ общения (протокол HTTP);
   - `127.0.0.1` — какой компьютер (это «я сам», как в уроке 1);
   - `5000` — какой порт, то есть какая программа на этом компьютере;
   - `/about` — какая страница нужна. Эту часть называют **путь**.
2. Браузер подключается по TCP к `127.0.0.1:5000`. Точно так же, как наш клиент из урока 1 делал `connect`.
3. Браузер отправляет **HTTP-запрос**. Это просто текст:
   ```
   GET /about HTTP/1.1
   Host: 127.0.0.1:5000
   ```
   `GET` значит «дай», дальше — путь.
4. Сервер отправляет **ответ** — тоже текст:
   ```
   HTTP/1.1 200 OK
   Content-Type: text/html; charset=utf-8

   <h1>О чате</h1>
   ...
   ```
   В первой строке **код ответа**: `200 OK` — «всё хорошо, держи», `404 Not Found` — «такой страницы нет». Дальше идут **заголовки**: например, `Content-Type` говорит, что пришёл HTML в кодировке UTF-8. После пустой строки — сам HTML.
5. Браузер рисует полученный HTML.

Вспомните урок 5: там мы придумали свой **протокол** — договорились, что каждое сообщение — это JSON в одной строке. HTTP — тоже протокол, только всемирный: на нём говорят все браузеры и все сайты.

## Что такое Flask

Чтобы сделать сайт, можно было бы взять сокеты из урока 1 и самому разбирать текст HTTP-запросов. Это возможно, но долго и полно мелочей. **Flask** делает эту работу за нас:
- слушает порт и принимает подключения;
- разбирает запрос: какой путь, какие данные;
- вызывает нужную **нашу** функцию;
- превращает то, что она вернула, в правильный HTTP-ответ.

Такие библиотеки называют **веб-фреймворками**. Flask — один из самых простых и популярных.

## Разбор кода

```python
from datetime import datetime

from flask import Flask
from markupsafe import escape
```

- `Flask` — главный класс фреймворка.
- `escape` — функция для безопасного вывода текста в HTML (см. «Безопасность» ниже). Её модуль `markupsafe` ставится вместе с Flask.

```python
app = Flask(__name__)
```

Создаём сайт — объект `app`. `__name__` — имя текущего модуля (вспомните `if __name__ == "__main__"`). По нему Flask понимает, где лежит программа, и в следующих уроках найдёт рядом папки с шаблонами и картинками.

### Маршруты

```python
@app.route("/")
def index():
    return """
    <h1>Школьный чат</h1>
    ...
    """
```

Строка с `@` над функцией называется **декоратором**. Не пугайтесь слова. Здесь он работает как наклейка на функции: «эта функция отвечает за адрес `/`». Flask запоминает пару «путь → функция». Такая пара называется **маршрутом**.

Когда придёт запрос `GET /`, Flask вызовет `index()`. Строку, которую вернула функция, он отправит браузеру как HTML с кодом `200`.

`"""` — многострочная строка Python: удобно для HTML в несколько строк.

`/` — это **главная** страница сайта: путь, когда в адресе после порта ничего нет.

```python
@app.route("/about")
def about():
    ...
```

Вторая страница — второй маршрут. Ссылка `<a href="/about">` на главной заставляет браузер отправить новый запрос `GET /about`.

> Пути в ссылках начинаются с `/` — это путь от «корня» сайта. Адрес компьютера и порт браузер подставит сам, тот же, что у текущей страницы.

### «Живая» страница

```python
@app.route("/time")
def show_time():
    now = datetime.now().strftime("%H:%M:%S")
    return f"<h1>Сейчас {now}</h1><p><a href=\"/\">← На главную</a></p>"
```

- `datetime.now()` — текущие дата и время, `strftime("%H:%M:%S")` превращает их в строку `12:05:33`. Часы `%H`, минуты `%M`, секунды `%S`.
- f-строка подставляет время в HTML.
- `\"` внутри строки — кавычка, которая не закрывает строку.

Функция выполняется **при каждом запросе**. Нажали F5 — новый запрос — новое время. Это главное отличие от HTML-файла из уроков 11–13, который всегда одинаковый.

Почему функция называется `show_time`, а не `time`? Чтобы не путать с модулем `time` из стандартной библиотеки. Имя функции может быть любым, оно не обязано совпадать с адресом.

### Параметр в адресе

```python
@app.route("/user/<name>")
def user(name):
    return f"<h1>Привет, {escape(name)}!</h1><p><a href=\"/\">← На главную</a></p>"
```

- `<name>` в маршруте — это «место для подстановки». Подходит любой путь вида `/user/что-угодно`.
- То, что стоит на этом месте, Flask передаёт в функцию параметром с тем же именем: для `/user/Аня` получится `name = "Аня"`.
- Слеш `/` в параметр не попадает: `/user/Аня/Боря` — это уже другой путь, его никто не обслуживает, ответ 404.

### Запуск

```python
if __name__ == "__main__":
    app.run(debug=True)
```

- `app.run()` запускает сайт и работает, пока его не остановят (Ctrl+C). Внутри — тот же цикл `accept`, что мы писали в уроке 3, причём каждый запрос обслуживается в своём потоке.
- По умолчанию сайт слушает адрес `127.0.0.1` и порт `5000`. Значит, открыть его можно только с этого же компьютера. Как пустить в чат другие компьютеры и телефоны, разберём в уроке 25.
- `debug=True` — **режим отладки**:
  1. Flask следит за файлами и перезапускается, когда вы сохраняете код. В терминале появляется `Detected change in ..., reloading`.
  2. Если в функции ошибка, браузер покажет подробный отчёт: какая ошибка, в какой строке, какие были переменные.

  Режим отладки нужен только при разработке. В отчёте об ошибке можно даже выполнять Python-код. Если такой сайт открыть для всей сети, любой сможет управлять вашим компьютером. В уроке 25 мы его выключим.

### Что пишет Flask в терминал

```
127.0.0.1 - - [04/Oct/2026 12:05:33] "GET /time HTTP/1.1" 200 -
127.0.0.1 - - [04/Oct/2026 12:05:33] "GET /favicon.ico HTTP/1.1" 404 -
```

На каждый запрос — строка: кто спросил, когда, что именно и с каким кодом ответили. `favicon.ico` браузер запрашивает сам: он ищет иконку для вкладки. У нас её нет, поэтому 404, и это не страшно.

## Подробный разбор: страница 404

Если адрес не подходит ни под один маршрут, Flask сам отвечает кодом **404** и стандартной страницей «Not Found». Нашу функцию он при этом не вызывает. Свою, красивую 404-страницу можно сделать в задании 6.

## Безопасность: зачем `escape`

Что будет, если вывести имя из адреса без `escape`?

```python
return f"<h1>Привет, {name}!</h1>"   # ОПАСНО
```

Откройте `http://127.0.0.1:5000/user/<b>Вася`. Имя стало **жирным**: браузер увидел `<b>` и принял его за тег. Это ещё безобидно. А вот такой адрес:

```
http://127.0.0.1:5000/user/<img src=x onerror=alert('Взлом!')>
```

Браузер пытается загрузить картинку `x`, это не получается, и он выполняет JavaScript из `onerror`. Вместо `alert` там мог быть код, который отправит злоумышленнику всё, что вы видите на странице. Достаточно прислать жертве такую ссылку.

Такая атака называется **XSS** (Cross-Site Scripting, «межсайтовое выполнение скриптов»). Правило против неё: **всё, что пришло от пользователя, перед вставкой в HTML нужно экранировать**.

`escape` заменяет опасные символы безопасными «кодами»:

| Было | Стало | Браузер покажет |
|---|---|---|
| `<` | `&lt;` | `<` |
| `>` | `&gt;` | `>` |
| `&` | `&amp;` | `&` |
| `"` | `&#34;` | `"` |

Браузер показывает эти коды как обычные символы и не принимает их за теги. Поэтому `/user/<b>Вася` выводит на экран ровно `<b>Вася`.

Не волнуйтесь, что придётся оборачивать каждую переменную: со следующего урока HTML будут собирать **шаблоны**, и они экранируют всё сами.

## Подробный разбор: кто такой `127.0.0.1`

Как в уроке 1, `127.0.0.1` — это «этот же компьютер». Если ученик откроет у себя `http://127.0.0.1:5000`, он попадёт на **свой** сайт, а не на сайт учителя. Чтобы открыть сайт соседа, нужен его IP-адрес в сети, а сайт должен слушать не только `127.0.0.1`. Это урок 25.

## Подробный разбор: что Flask возвращает браузеру

Функция-страница может вернуть не только строку.

- **Строку** — Flask отправит её как HTML с кодом 200.
- **Пару «текст, код»**: `return "Нет такого", 404` — свой код ответа.
- **Словарь или список** — Flask превратит его в JSON (как `json.dumps` в уроке 5) и поставит заголовок `Content-Type: application/json`. Так делают «API» для программ, а не для людей. Это задание 8 и большой урок 22.

## Шпаргалка

| Что нужно | Как написать |
|---|---|
| Создать сайт | `app = Flask(__name__)` |
| Новая страница | `@app.route("/путь")` + функция, которая возвращает HTML |
| Часть адреса — в параметр | `@app.route("/user/<name>")` → `def user(name):` |
| Только числа | `@app.route("/square/<int:n>")` (задание 4) |
| Свой код ответа | `return "текст", 404` |
| Безопасно вставить текст | `escape(текст)` |
| Запустить | `app.run(debug=True)` → `http://127.0.0.1:5000/` |
| Остановить | Ctrl+C в терминале |
