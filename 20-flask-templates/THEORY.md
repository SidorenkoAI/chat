# Урок 20. Шаблоны и статика — теория и разбор кода

На уроке 19 HTML жил в строках Python. Для страницы из пары строк это нормально. Но страница чата — это 50 строк HTML со стилями, и собирать её f-строками неудобно. Сегодня HTML переезжает в отдельные файлы-**шаблоны**, а Python только подставляет в них данные.

## Как устроена папка

```
20-flask-templates/
  app.py             ← программа: маршруты и данные
  templates/         ← шаблоны: HTML с «дырками» для данных
    base.html        ← общий скелет: <head>, шапка, меню
    index.html       ← страница чата
    about.html       ← страница «О чате»
  static/            ← файлы, которые отдаются как есть
    style.css
```

Flask сам ищет шаблоны в папке `templates`, а статические файлы — в папке `static` рядом с программой. Отсюда и `Flask(__name__)`: по имени модуля Flask узнаёт, где лежит `app.py`, и находит папки рядом.

## Разбор `app.py`

```python
from flask import Flask, render_template
```

`render_template` — функция, которая превращает шаблон и данные в готовый HTML.

```python
ME = "Аня"

MESSAGES = [
    {"author": None, "text": "Боря присоединился к чату", "time": "10:14"},
    {"author": "Боря", "text": "Привет всем!", "time": "10:15"},
    ...
]

ONLINE = ["Аня", "Боря", "Вова"]
```

Данные страницы. Каждое сообщение — словарь с автором, текстом и временем (вспомните JSON-сообщения из урока 5: там была та же идея). У системных сообщений автора нет — `None`.

Пока это просто списки в программе: на следующем уроке сообщения будут добавляться через форму, а в уроке 23 придут из базы данных чата.

```python
@app.route("/")
def index():
    return render_template("index.html", me=ME, messages=MESSAGES, online=ONLINE)
```

`render_template`:
1. находит файл `templates/index.html`;
2. делает доступными в нём переменные `me`, `messages`, `online`. Имена слева от `=` — это имена **внутри шаблона**;
3. выполняет все `{{ }}` и `{% %}` и возвращает готовый HTML-текст.

Функция возвращает этот текст, Flask отправляет его браузеру. Для браузера ничего не изменилось: он получил обычный HTML, как на уроке 19.

## Язык шаблонов Jinja

### Вставка значения: `{{ … }}`

```html
<b class="author">{{ m.author }}</b>
```

Внутри двойных фигурных скобок — выражение. Его значение вставляется в HTML. Это как `{}` в f-строке.

**Точка** в Jinja достаёт и атрибут объекта, и элемент словаря: `m.author` для словаря значит `m["author"]`. Писать `m["author"]` тоже можно, но с точкой короче.

### Фильтры: `|`

```html
<h2>В сети: {{ online|length }}</h2>
```

Вертикальная черта передаёт значение в **фильтр** — маленькую функцию. `online|length` — то же, что `len(online)` в Python. Полезные фильтры:

| Фильтр | Что делает | Пример |
|---|---|---|
| `length` | длина | `{{ online|length }}` → `3` |
| `upper`, `lower` | регистр | `{{ "аня"|upper }}` → `АНЯ` |
| `first`, `last` | первый, последний элемент | `{{ m.author|first }}` → `А` |
| `default` | значение, если переменной нет | `{{ m.time|default("--:--") }}` |
| `join` | склеить список | `{{ online|join(", ") }}` → `Аня, Боря, Вова` |

Свой фильтр тоже можно написать на Python — это задание 8.

### Цикл: `{% for %}`

```html
<ul id="online">
  {% for name in online %}
    <li>{{ name }}</li>
  {% endfor %}
</ul>
```

`{% … %}` — это **команды** шаблона, а не вставка значения. `for` работает как в Python: кусок HTML между `for` и `endfor` повторится для каждого элемента списка. В Python конец блока видно по отступу, а в HTML отступы ничего не значат. Поэтому конец цикла нужно написать явно: `{% endfor %}`.

Внутри цикла доступна особая переменная `loop`: `loop.index` — номер повторения (с 1), `loop.first` и `loop.last` — первое ли это повторение и последнее ли (задание 1).

Если список пустой, можно показать что-то вместо него:

```html
{% for m in messages %}
  ...
{% else %}
  <p>Сообщений пока нет</p>
{% endfor %}
```

### Условие: `{% if %}`

```html
{% if m.author is none %}
  <div class="message system">{{ m.text }}</div>
{% else %}
  <div class="message {% if m.author == me %}mine{% endif %}">
    ...
  </div>
{% endif %}
```

- `m.author is none` — «автор равен `None`». В Jinja `none` пишется с маленькой буквы. В Python было бы `m["author"] is None`.
- Внутри `{% if %}` можно писать то же, что в Python: `==`, `!=`, `and`, `or`, `not`, `in`.
- Второй `if` стоит прямо внутри атрибута `class`. Для сообщения Ани получится `class="message mine"`, для остальных — `class="message "`. Лишний пробел браузеру не мешает.

### Сравнение с уроком 13

В уроке 13 сообщения на страницу добавлял **JavaScript в браузере**: `createElement`, `className`, `append`. Здесь ту же работу делает **Python на сервере**, ещё до того, как страница попадёт в браузер. ## Наследование шаблонов

У страниц «Чат» и «О чате» одинаковые `<head>`, шапка и меню. Копировать их в каждый файл — значит потом исправлять в нескольких местах (вспомните задание 3 урока 19). Поэтому общая часть живёт в одном файле.

### `base.html` — «родитель»

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>{% block title %}Школьный чат{% endblock %}</title>
  <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
</head>
<body>
  <header>
    <h1>Школьный чат</h1>
    <nav>
      <a href="{{ url_for('index') }}">Чат</a>
      <a href="{{ url_for('about') }}">О чате</a>
    </nav>
  </header>

  {% block content %}{% endblock %}
</body>
</html>
```

`{% block имя %}…{% endblock %}` — это **место, которое «дети» могут заменить своим содержимым**. В `title` по умолчанию стоит «Школьный чат», а `content` по умолчанию пустой.

### `index.html` и `about.html` — «дети»

```html
{% extends "base.html" %}

{% block content %}
<main>
  ...
</main>
{% endblock %}
```

- `{% extends "base.html" %}` — «возьми `base.html` целиком».
- `{% block content %}` — «а вот этот блок замени моим содержимым».
- Всё, что в «ребёнке» написано **вне** блоков, игнорируется.

`about.html` заменяет ещё и заголовок вкладки:

```html
{% block title %}О чате — Школьный чат{% endblock %}
```

А `index.html` блок `title` не трогает, поэтому у него заголовок по умолчанию.

## `url_for` — адреса по имени функции

```html
<a href="{{ url_for('about') }}">О чате</a>
<link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
```

- `url_for('about')` — «адрес страницы, за которую отвечает функция `about`». Вернёт `/about`. Если завтра поменять маршрут на `@app.route("/o-chate")`, все ссылки обновятся сами.
- `url_for('static', filename='style.css')` — адрес файла из папки `static`. Вернёт `/static/style.css`.
- Для маршрута с параметром параметр передаётся по имени: `url_for('user', name='Боря')` → `/user/Боря` (задание 5).

### Подробный разбор: почему не просто `href="style.css"`

В уроке 12 страница открывалась с диска, и `style.css` лежал рядом с `index.html`. Теперь страницу отдаёт Flask по адресу `/`. Браузер видит `href="style.css"` и запрашивает `/style.css`. Но такого маршрута нет — **404**. Файлы из `static/` Flask раздаёт по адресам `/static/…`. `url_for` знает это правило и пишет адрес правильно.

## Статика

Файлы из `static/` Flask отдаёт как есть, ничего в них не подставляя. Отсюда и название: «статические», то есть неизменные. В отличие от шаблонов, в `style.css` нельзя написать `{{ }}`: Flask его не обрабатывает.

Тип файла (`Content-Type`) Flask определяет по расширению: `.css` — стили, `.js` — скрипт, `.png` — картинка.

## Безопасность: шаблоны экранируют сами

В `MESSAGES` есть сообщение Вовы:

```python
{"author": "Вова", "text": "Я сделал. А как в HTML сделать текст <b>жирным</b>?", ...}
```

На странице видно `<b>жирным</b>` как обычный текст. Jinja в Flask **автоматически экранирует** всё, что вставляется через `{{ }}`: `<` превращается в `&lt;`, `>` — в `&gt;` (таблица — в THEORY.md урока 19). Писать `escape` больше не нужно.

Это очень важно для чата: сообщения пишут люди, и кто-нибудь обязательно попробует отправить `<script>`. На следующем уроке так и сделаем, и ничего не сломается.

Выключить экранирование можно фильтром `|safe`: `{{ m.text|safe }}`. Делать так можно **только** с текстом, который написал сам программист, а не пользователь. Иначе — XSS (урок 19).

## Шпаргалка

| Что нужно | Как написать |
|---|---|
| Отдать шаблон | `return render_template("index.html", имя=значение)` |
| Вставить значение | `{{ имя }}`, `{{ m.text }}` |
| Фильтр | `{{ online|length }}`, `{{ name|upper }}` |
| Цикл | `{% for x in список %} … {% endfor %}` |
| Номер в цикле | `{{ loop.index }}` |
| Пустой список | `{% for … %} … {% else %} пусто {% endfor %}` |
| Условие | `{% if условие %} … {% elif … %} … {% else %} … {% endif %}` |
| Наследование | `{% extends "base.html" %}` + `{% block content %} … {% endblock %}` |
| Адрес страницы | `{{ url_for('about') }}`, `{{ url_for('user', name='Боря') }}` |
| Адрес файла из `static/` | `{{ url_for('static', filename='style.css') }}` |
| Комментарий в шаблоне | `{# не попадёт в HTML #}` |
